- `NYC-Taxi_All_Models.ipynb`: ABT to all models. Naive baseline, XGBoost (Champion), SVR (Challenger 1) and Neural Network (Challenger 2), compared on the same held-out test period.
- `NYC_Taxi_ABT.csv`: the Analytical Base Table (not in version control; about 1 GB).
- `NYC_Data_Dictionary.pdf`: data dictionary for every ABT column.
- `Perscriptive_GRP1_Ref.pdf`: references (APA 7th edition) with the data dictionary as an appendix.
- `NYC_architecture_plan.drawio`: model architecture diagram.
